# 🍿 StreamHub — Curated Link Directory

A sleek, dark-mode streaming bookmark aggregator and launch dashboard inspired by TBCPL. Built as a lightweight, single-page application that runs directly in the browser with no build steps required.

## ✨ Features

* **Glassmorphic Dark UI**: Deep purple aesthetic with Tailwind CSS and Lucide icons.
* **Instant Fuzzy Search**: Real-time filtering across titles, tags, and descriptions.
* **Category Filtering**: Quickly filter links by Movies, Anime, Manga, Sports, Paid, and Apps.
* **Recently Opened Strip**: Tracks and surfaces your latest visited links for one-click access.
* **Favorites System**: Pin your go-to sites with a single click.
* **Add & Manage Links**: Add custom sites directly through the in-app modal.
* **Zero Backend Required**: All custom links, favorites, and recent history persist locally via `localStorage`.
